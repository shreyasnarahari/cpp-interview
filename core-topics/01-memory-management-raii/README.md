# Memory Management & RAII

## Folder Structure


---

## How to Approach

**If you're new to the topic:**
1. Read `resources.md` — follow the reading order, takes ~1.5 hours total
2. Come back and drill `question-bank/easy.md`

**If you know the basics:**
1. Open `question-bank/real-interview-q-a.md` — attempt each question cold
2. Cross-check answers in `easy.md`, `medium.md`, or `hard.md`

**For interview prep (day before):**
1. Skim `question-bank/real-interview-q-a.md` — theory questions only
2. Run through the "What's wrong?" code questions mentally
3. Re-implement the coding problems in `hard.md` from scratch
