# Modern C++ Features — Learning Resources

---

### 1. cppreference — C++ Version History
https://en.cppreference.com/w/cpp/compiler_support

Complete feature table by compiler and standard version. Use as a reference to check what's available.
**Time: 10 min (bookmark it)**

---

### 2. C++17 — The Complete Guide (Nicolai Josuttis)
Book — the best single resource for C++17. Covers every feature with practical examples.
Key chapters: structured bindings, `if constexpr`, `std::optional/variant/any`, fold expressions, CTAD.
**Time: 1.5–2 hours (selected chapters)**

---

### 3. A Tour of C++ (3rd Edition) — Bjarne Stroustrup
Book — concise overview of modern C++ (through C++20) by the language creator. Excellent for interview-level breadth.
**Time: 2–3 hours**

---

### 4. C++20 Features — Rainer Grimm (Modernes C++)
https://www.modernescpp.com/index.php/thebigfour

Multi-part series covering the Big Four of C++20: concepts, ranges, coroutines, and modules.
**Time: 40 min**

---

### 5. What's New in C++23 — CppCon
https://www.youtube.com/watch?v=Cttb8vMuq-Y

Overview of C++23 features including `std::expected`, deducing `this`, `std::print`, and `std::flat_map`.
**Time: 60 min (watch at 1.5x → 40 min)**

---

### 6. Jason Turner — C++ Weekly
https://www.youtube.com/@caborern/videos

Short (5–10 min) videos each covering a single C++ feature. Great for filling gaps.
**Time: 10 min per video, watch as needed**
