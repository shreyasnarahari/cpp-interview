## How to Approach

**Day-before review:**
1. "What's new in C++17?" — structured bindings, `if constexpr`, `std::optional`, `std::variant`, fold expressions, CTAD
2. "What's new in C++20?" — concepts, ranges, coroutines, modules, `consteval`, three-way comparison
3. "What's new in C++23?" — `std::expected`, deducing this, `std::print`, `std::flat_map`
4. Know at least 3 features per standard with concrete code examples

## Why This Matters

"What C++ standard do you use?" and "What's your favorite modern C++ feature?" are common warm-up questions at FAANG. They signal how current your knowledge is. Candidates stuck on C++03 patterns are red flags.
