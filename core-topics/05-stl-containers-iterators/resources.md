# STL Containers & Iterators — Learning Resources

---

### 1. cppreference — Containers Library
https://en.cppreference.com/w/cpp/container

The definitive reference. For each container, read the complexity guarantees and iterator invalidation notes.
**Time: 30 min (skim main containers)**

---

### 2. C++ STL Tutorial — learncpp.com
https://www.learncpp.com/cpp-tutorial/introduction-to-standard-library-algorithms/

Beginner-friendly introduction to STL containers and algorithms with examples.
**Time: 30–40 min**

---

### 3. Back to Basics: Iterators — CppCon
https://www.youtube.com/watch?v=26aW6aBVpk0

Comprehensive talk on iterator categories, invalidation rules, and common pitfalls.
**Time: 60 min (watch at 1.5x → 40 min)**

---

### 4. Effective STL — Scott Meyers
Book: "Effective STL"

Key items:
- Item 1: Choose your containers with care
- Item 4: Call empty() instead of checking size() against zero
- Item 14: Use reserve to avoid unnecessary reallocations
- Item 32: Follow remove-erase idiom
- Item 43: Prefer algorithm calls to hand-written loops
**Time: 45 min**

---

### 5. The C++ Standard Library — Nicolai Josuttis
Book — encyclopedic reference. Use Chapter 7 (Containers) and Chapter 11 (Algorithms) as reference.
**Time: Reference (look up as needed)**
