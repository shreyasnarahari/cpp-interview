## How to Approach

**If you're new:**
1. Read `resources.md` — takes ~1.5 hours
2. Drill `question-bank/easy.md`

**If you know the basics:**
1. Open `question-bank/real-interview-q-a.md` — attempt cold
2. Cross-check in easy/medium/hard

**Day-before review:**
1. Virtual dispatch in constructors — know it cold
2. Object slicing and why polymorphism requires pointers/references
3. Diamond problem and virtual inheritance
4. Rule of Zero / Five — when each applies
